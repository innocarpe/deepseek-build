## 4. Design summary (pointer — ADR is normative)

Full decision text: [`docs/adr/0010-spec-45-snippet-store.md`](../../adr/0010-spec-45-snippet-store.md).

Short map for reviewers:

| Topic | Decision headline |
|-------|-------------------|
| Ownership | Path A owns product enforcement; thin `dsb-tools::SnippetStore` is **reference design + test oracle**, port/adapt into Grok boundaries |
| ID shape | Opaque `snp_<ulid>` session-local; never path-as-id |
| Version | `hex(sha256(full_file_bytes))` only for edit check (mtime alone rejected) |
| Range | Inclusive 1-based line range (M2 default from Spec 45) |
| Edit | Permission → resolve id → version → scope-only literal match → atomic write → expire path |
| `expected_count` | If **set**, **must equal** actual occurrence count inside scope (Spec 45); count `1` is **not** exempt — mismatch → `expected_count_mismatch` (do not copy thin-store `count==1` ignore) |
| Write | Create-only default; overwrite only policy-granted; then expire path |
| Bash / external | Touched paths expire; unknown mutation set → expire all workspace file snippets |
| Prefix | Snippet table **excluded** from stable prefix (Spec 10) |
| Follow-on | VC003 mint · VC004 require · VC005 write/bash · VC006 cut 5.2.0 |

Thin store gaps the ADR closes for Path A (fields / behaviors not fully correct on thin `Snippet` / edit today): `encoding`, `issued_at_turn`, symlink resolve policy, binary no-snippet, candidate snippet returns on `ambiguous_match`, **`expected_count` must equal actual count even when count is 1**, subagent ownership, resume/fork tables.
