## 3. V3-60-3 close attempt (narrow only)

### 3.1 Spec / call-path facts (inspected before design)

| Layer | Fact |
|-------|------|
| Spec 60 §1.2 / T3 | Implement worker mutates → parent **snippet table expires** (product default: all) **or** touched paths |
| Thin Path B | `dsb_agent::parent_after_worker` → `snippets.expire_all()` when `mutated` — unit `implement_write_mutates` **green** — **not** Path A sole proof |
| Path A store | Grok `SessionSnippetStore` is **session-local** (`Resources` bag); mint on `read_file`; require on `search_replace`; expire on parent-side write/bash/search_replace |
| Path A spawn | Public tool `spawn_subagent` / implement-class `general-purpose`; child session has **separate** resources |
| Parent after child | **No** existing Path A hook found that calls `expire_all` / `expire_path` on parent store when implement-class child mutates |
| Content safety | Parent edit with pre-mutation `snippet_id` after **same path** disk change should hit **`snippet_stale`** (version ≠ current) even if id remains in table — per VC004/VC005 search_replace gate |

### 3.2 Acceptable close (user bar)

Public `deepseek-build` / `dsb` Path A hermetic R0A:

1. Parent mints/holds `snippet_id` for path **P**.
2. Implement-class worker mutates **P**.
3. Parent subsequent edit using the **pre-mutation** `snippet_id` is **rejected**, **or** real parent table expiry is observed.
4. Wire + META under `docs/product/evidence/`; public entry (no `DEEPSEEK_BUILD_AGENT_BIN` for the claim).

Thin units / docs alone → **do not close**.

### 3.3 Attempt strategy (ordered)

1. **R0A-first (prefer no product invent):** extend hermetic fixture + public harness scenario `parent-worker-snippet-stale` (or VC015-named):
   - Seed `parent_seed.txt`
   - Parent `read_file` → capture `snippet_id`
   - `spawn_subagent` general-purpose mutates `parent_seed.txt`
   - Parent `search_replace` with stale `snippet_id` + original old_string → expect tool error (`snippet_stale` / `snippet_not_found` / equivalent)
   - Final token `parent-worker-snippet-stale-ok`
2. If R0A **PASS** on public entry → record **V3-60-3 CLOSED** with **honest mechanism** (stale-edit reject vs table expire). Prefer table-expire if a **narrow** existing-spec hook is already reachable; **do not** invent a fake stamp file.
3. If R0A cannot prove without large new spawn/completion plumbing across parent resources → **stop**; residual remains exact; freeze **BLOCKED**.
